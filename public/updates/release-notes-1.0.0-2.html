StylePort 1.0.0 (2)

StylePort brings your own CSS and UserCSS styles to Safari on macOS 14 or later.

  • Import a style from a file, URL, or pasted CSS.
  • Manage a local style library, edit styles, and configure supported UserCSS variables.
  • Export and restore backups of your styles and settings.
  • Return from the editor to the Style Library in the same tab, without a navigation-related error banner.
  • The direct-download edition includes Sparkle update checking and optional website tips. Styling features are free.

Before installing

Export your style library first. The direct-download and App Store/TestFlight editions replace one another; they are not intended to run side by side. Safari may need to be restarted after replacement.

Automatic update checks require your opt-in and run while the companion app is open. You can check manually from the StylePort app. The updater verifies signed feeds and downloads.
